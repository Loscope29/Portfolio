Etude Statistique Environnementale (Mercury Data)

Réalisation d'une analyse complète d'impact environnemental (niveaux de mercure selon le pH, le calcium et l'alcalinité). Utilisation intensive de l'écosystème Tidyverse, ggplot2 et corrplot.

Régression Linéaire Multiple
Matrice de Corrélation
RMarkdown dynamique
DARRYL_NOAH_DATAVIZ_CA.Rmd 
library(tidyverse)
library(corrplot)

# Import & Nettoyage
Mercury <- read.csv('Mercury Data.csv', sep=";")

# Matrice de corrélation
correlation <- cor(select(Mercury, where(is.numeric)))
corrplot(correlation, method = "color", type = "upper")

# Régression linéaire
model <- lm(StdMercury ~ pH + Calcium + Alkalinity, data=Mercury)
summary(model)
